### Ваши друзья в VK — это не просто список. Это ваша целевая аудитория. Вы просто об этом не знали.

Признайтесь, вы думали, ваши друзья в соцсетях — это случайный набор людей? Как бы не так. Это стройная (хотя и хорошо замаскированная) система сообществ по интересам. И у нас есть инструмент, который это доказывает.

**TargetGraph** превращает хаотичный список друзей в интерактивную карту социальных связей и интересов. Изначально это был инструмент для параноиков, чтобы увидеть, "кто с кем дружит". Теперь это — оружие для таргетолога, который хочет понимать *почему* они дружат.

## 🚀 Что это такое, если по-человечески?

**Представьте:**
Вы вводите ID любого пользователя VK. Наш движок проходит по его друзьям, заглядывает к *друзьям его друзей*, анализирует их интересы и группы.

**На выходе вы получаете не скучный отчет, а... [Карту Его Вселенной](assets/demo_graph.png):**
*   **Интерактивный граф** в [Obsidian.md](https://obsidian.md), где связи видны невооруженным глазом.
*   **Цветовую дифференциацию** групп по интересам.
*   **"Живые досье"** — каждый узел это `.md`-файл с данными пользователя, где вы можете вести свои заметки.

**Что это даёт бизнесу?**
*  ### **Ах, вот кто ты такой на самом деле !?:** 
* Увидеть, как чётко аудитория делится на "геймеров", "родителей" и "любителей редких кактусов". Это просто весело.
*   ### **А теперь серьёзно:** 
* Эта же технология позволяет найти не просто "мужчин 25-35", а "мужчин 25-35, которые дружат с гитаристами, фанатами "Игры Престолов" и покупают кофе в зёрнах". Вы целитесь не в демографию, а в реальное, живое сообщество.

## 🛠 Техническое Сердце

Это не скрипт, написанный на коленке. Это спроектированная система.

### Эскиз предварительно на планируемую разработку

├── pyproject.toml # Poetry: зависимости, линтинг, сборка\
├── poetry.lock > Детализированный лок (не трогать!)\
├── .env.example > Шаблон для переменных окружения\
├── .gitignore > Стандартный + Poetry/.env\
└── README.md # Этот файл\


**Технологический стек, который намного круче, чем "напишу на requests и json":**
*   **Управление зависимостями:** [Poetry](https://python-poetry.org/) (никаких `pip freeze > requirements.txt`)
*   **Графы:** [NetworkX](https://networkx.org/) — промышленный стандарт.
*   **HTTP-клиент:** [httpx](https://www.python-httpx.org/) (асинхронность на подходе).
*   **Конфиги:** `pydantic_settings` — валидация на входе.
*   **Тесты:** `pytest` — потому что без тестов это просто хобби.
*   **Стиль кода:** `black`, `isort` — единство стиля — признак профессионализма.

## 📦 Быстрый Старт

### 1. Клонируем и настраиваем

 Далее : ниже следует не шалить с кнопочками, по не опытности проект запустится, не паникуй 152ФЗ тебе не страшен\
 пока ты не вставил чейто ID для обработки (короче я тебя предупреждаю учи законы перед тем ка жать на кнопки)

```bash
git clone https://github.com/Lazarus-Phoenix/NetworkX_friend_net_graph_system.git
cd NetworkX_friend_net_graph_system

2. Устанавливаем зависимости (через Poetry)
bash
poetry install
3. Настраиваем окружение
bash
cp .env.example .env
# Отредактируй .env: вставь свой VK API Token
# VK_API_TOKEN=your_super_secret_token_here
Важно: Токен получаем тут: VK API: Access Token. Используем Standalone-приложение. НИКОМУ НЕ ПОКАЗЫВАЕМ свой токен и .env файл!

4. Запускаем!
bash
# Активируем виртуальное окружение Poetry
poetry shell

# Строим граф для пользователя с ID 123456789
python -m friend_net.main --user-id 123456789 --output-dir ./my_target_analysis
Готово! Открой папку my_target_analysis в Obsidian.md и смотри на социальную вселенную своего клиента (или конкурента).

🧪 Для Разработчиков
```
